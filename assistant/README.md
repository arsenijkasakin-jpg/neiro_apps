# JARVIS — голосовой ПК-ассистент

Графический русскоязычный ассистент с локальной нейросетью Ollama.

## Возможности

- компактный тёмный графический интерфейс;
- чат с локальной моделью Ollama;
- автоматическое получение списка моделей Ollama;
- голосовой ввод через микрофон;
- озвучивание ответов;
- запуск программ Windows;
- открытие сайтов и поиск;
- скриншоты;
- блокировка ПК;
- подтверждение выключения и перезагрузки;
- режим повторного прослушивания.

## Запуск

1. Установить Python 3.13.
2. Запустить `install_dependencies.bat`.
3. Убедиться, что Ollama запущена.
4. Установить модель, например:

```bat
ollama pull qwen2.5:3b
```

5. Запустить `start_jarvis.bat`.

## Примечание

Распознавание речи через SpeechRecognition/Google требует интернет-соединения. Ответы нейросети работают через локальную Ollama.
