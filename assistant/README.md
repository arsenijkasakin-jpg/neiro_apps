# JARVIS — голосовой ПК-ассистент

Первый рабочий прототип ассистента под Windows.

## Возможности

- распознавание русской речи через микрофон;
- озвучивание ответов через системный TTS;
- разговор с локальной моделью Ollama;
- открытие базовых приложений;
- открытие сайтов и поиск в браузере;
- скриншоты;
- блокировка компьютера;
- управление громкостью;
- подтверждение потенциально опасных команд выключения/перезагрузки.

## Установка

1. Установить Python 3.11+.
2. Установить зависимости:

```bash
pip install -r requirements.txt
```

3. Установить Ollama и скачать модель из `config.json`.
4. Запустить:

```bash
python assistant.py
```

Распознавание речи в этой версии использует Google Speech Recognition, поэтому для распознавания нужен интернет. Ответы модели при этом идут через локальную Ollama.
