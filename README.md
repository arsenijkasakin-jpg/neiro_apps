# neiro_apps

Проекты пользователя в одном репозитории.

## Проекты

### `assistant/`
Прототип голосового ПК-ассистента в стиле JARVIS: распознавание русской речи, озвучивание, локальная LLM через Ollama и базовое управление Windows.

### `endfield_quiz/`
Фанатская викторина по Arknights: Endfield.
